# Java 客户送评与支付功能本地验收（2026-09-08）

本次更新已运行在本机 Java 后端 8088、用户站 3000 和管理端 3001。没有部署生产、提交或推送 Git，也没有修改 Python 系统的 `Data/`。

## 已完成

- 用户订单详情展示下单、付款、寄入、收货、评级、复核封装、回寄、签收八个阶段；寄入和回寄分别显示承运商、运单号、物流轨迹与时间，可展开完整订单历史。页面可见时每 20 秒刷新，也支持手动刷新。
- 寄入签收不会误显示为订单完成；回寄签收同步更新订单和卡片状态。迟到的物流扫描不会让已签收状态倒退，已签收订单的进度全部完成。
- 企业客户具备公司资料、预充值申请、财务核款、按币种独立余额和流水。付款使用订单同币种余额，支持幂等请求和并发扣款；符合条件的取消按原币种退款一次。
- 支持 USD、CNY、EUR、GBP、HKD、JPY、CAD、AUD、SGD 的价格与钱包配置，JPY 禁止小数；评级和回寄报价使用同一币种，不进行隐式汇率换算。原库目前只配置 USD 评级价格，其他币种需在管理端“评级与回寄价格配置”补充。
- 管理端“系统设置 → 支付渠道”提供微信 Native、支付宝当面付、PayPal Orders v2 的配置。凭据加密保存且不回显，渠道按配置完整性启用；回调校验商户、签名、金额、币种和交易唯一性。
- 退款、撤销等财务异常暂停履约，普通收货、质检、评级关联、任务或例外处理不能解除财务冻结；物流事实仍可记录。
- 补充邮件验证、密码重置和订单通知接口。重置令牌限时且只能使用一次，重置后撤销账号会话；通知支持加密 outbox 和失败重试。
