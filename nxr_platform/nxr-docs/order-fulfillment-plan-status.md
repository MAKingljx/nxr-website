# Java 送评履约开发计划完成度

核对基准为飞书 `NXR_Java_送检流程开发计划_8周`，共 30 项。本文只描述本地 Java 工作区 `nxr_platform/`；不代表 Python 生产系统已经切换，也不代表已经完成真实支付、承运商或业务人员验收。

## 业务边界

本期“产品售卖”售卖的是基础评级服务，不是通用实物商城。客户按卡牌语种和数量购买评级服务，预付回寄运费后把卡寄到 NXR；后台完成入库、评级、封装、终检和回寄。`graded_card` 表示 graded card（已评级卡），不是“经典卡”；经典/复古产品使用 `vintage_product`。
