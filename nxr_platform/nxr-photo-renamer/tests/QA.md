# 验收范围

自动化测试使用合成图片和隔离目录；用户授权的真实图片验收只操作独立副本。原生目录选择器的自动化替代与真实浏览器文件 API 验证必须分开描述。

| 用户操作或结论                                    | 验证方式                                      | 视觉状态                   |
| ------------------------------------------------- | --------------------------------------------- | -------------------------- |
| 选择文件夹、稳定按名称排序、仅当前层图片          | 浏览器沙盒目录；数字排序单元测试              | 空页面、文件列表、长文件名 |
| 本地识别有效 QR、拒绝外域/非法路径、支持旋转/多码 | 合成真实二维码，worker 实际解码；URL 单元测试 | 扫描中、成功、需要检查     |
| 停止、重新识别                                    | 页面按钮；取消后保留已扫描状态                | 进度及可继续操作的状态     |
| 最多两张并行扫码、乱序完成不改变配对、补扫跳过已配对正图 | 可控 Worker 完成顺序、停止后重扫；真实照片耗时对比 | 两张进行中、完成计数、按原顺序显示结果 |
| 唯一 QR 图固定为 B、前一张固定为 A               | 浏览器顺序场景及配对单元测试                  | 只读命名预览               |
| 重复证号、同名目标、重复照片不执行                | 纯逻辑和文件操作预检                          | 冲突说明与禁用按钮         |
| 确认前不修改，WebP 像素与尺寸不变，备份原字节一致 | 真实浏览器文件 API、RGBA 与 SHA-256；取消确认 | 完整改名预览、成功提示     |
| 中断、写失败时原件或核验副本保留                  | 故障注入测试                                  | 错误提示与操作记录         |
| 恢复原名称且不覆盖外部修改                        | 文件操作测试及浏览器恢复                      | 恢复确认与已恢复记录       |
| 权限拒绝和只读预览                                | picker 权限替代；真实 file input              | 权限提示、执行禁用         |
| 排除整组、隐藏导出清单                            | 浏览器取消勾选，检查确认清单和按钮是否隐藏    | 组选择与确认清单           |
| 页面可读、不溢出                                  | 桌面和 390px 截图及尺寸检查                   | 空态、配对、确认弹窗       |

需要特别区分：OPFS 沙盒使用真实 `FileSystemDirectoryHandle`、`createWritable`、`removeEntry`，但不等于已经自动操作了系统的原生文件夹选择对话框。原生选择器的实际验收结果单独记录在最终交付说明中。
